# R2 housing — editable source and print outputs

[smove-r2-enclosure.FCStd](smove-r2-enclosure.FCStd) is the single current native editable FreeCAD source, including Parameters spreadsheet and CSG features. Geometry is preserved, not regenerated by this cleanup.

- [Base STL](dist/base.stl), [lid STL](dist/lid.stl).
- [Assembly STEP](dist/smove-r2-assembly.step), [printable STEP](dist/smove-r2-printable.step).
- Existing PNG previews in `dist/` are retained reference images, not new GUI review.
- [Printing, hardware and assembly limits](PRINTING-ASSEMBLY.md).
- [Source/output manifest](dist/manifest.json).

The parametric generator is `scripts/r2/enclosure/generate.py`, dispatched through [entry.py](entry.py). Inputs are the canonical `PCB/main` and `PCB/imu-carrier` board/interface files, extracted into ignored `.cache/housing/input-geometry.json`; no duplicate visible KiCad projects are needed. `validation/build.json` records the preserved native build parameters; it is provenance, not a fresh validation report.

[Reproduction commands and runtime limitations](../docs/revision-r2/final-export/README.md). The pinned bootstrap is retained but no large runtime is downloaded for cleanup. Fit, retention, cable, pack and radio qualification remain open. No manufacturing or charging approval.
