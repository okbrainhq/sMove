## Read-only verification from repository root

Requires installed KiCad CLI/Python pcbnew and Python. Run with the system interpreter, not a Python missing pcbnew:

```sh
/usr/bin/python3 scripts/r2/main/verify.py
/usr/bin/python3 scripts/r2/imu-carrier/verify.py
/usr/bin/python3 scripts/r2/electrical-completion/capacitance.py
/usr/bin/python3 scripts/r2/electrical-completion/verify.py
/usr/bin/python3 scripts/r2/enclosure/extract.py
/usr/bin/python3 scripts/r2/enclosure/contact_audit.py
/usr/bin/python3 scripts/r2/final/package.py
```

Main and carrier verifiers run fresh configured ERC/DRC and export XML nets into `.cache/verify/<board>/`. The combined electrical verifier consumes those reports; run in the listed order. Capacitance reads exact archived Samsung curves, not the network. Extraction reads canonical boards directly and writes transient `.cache/housing/` inputs. Contact audit checks current stored copper against retention lands.

`package.py` validates standalone files, native BOM/CPL refs/CIDs/positions, local libraries/models, per-design manifests, fabrication-only ZIP CRC/raw equality, FCStd container integrity and current Markdown links. It creates **no release archive**. `--seal` refreshes manifests after intentional output changes; it does not establish historical parity.

Configured severity only: ignored native defaults remain ignored (`footprint_filters_mismatch`, `footprint_type_mismatch`, `missing_courtyard`, `npth_inside_courtyard`, `pth_inside_courtyard`). No rule relaxation or new DRC exclusions. Retired archival-preservation checks are explicitly not passing current tests. See cleanup evidence for actual results; the historical 1938 FreeCAD checks are **not a new run**.

## Optional regeneration — overwrites exports, not needed for cleanup

```sh
/usr/bin/python3 scripts/r2/final/export.py
/usr/bin/python3 scripts/r2/final/package.py --seal
```

The final exporter keeps native PCB/schematic/project bytes unchanged and produces separate fabrication ZIP/BOM/pick-and-place files, PDFs and previews in each board's dist. It requires Poppler and installed KiCad model libraries for its optional native render/STEP operations. Those heavyweight exports are not rerun merely to move files; timestamps may differ on regeneration. Retained conservative-envelope populated STEP outputs are preserved reference deliverables, not regenerated by this exporter.

## Optional FreeCAD reproduction

The pinned runtime lock is `housing/toolchain.lock.json`. If no local runtime is available, `scripts/freecad/bootstrap.py` can provision it explicitly; cleanup does not download it. With that runtime installed:

```sh
/usr/bin/python3 scripts/r2/enclosure/extract.py
/usr/bin/python3 scripts/freecad/run.py housing/entry.py generate
/usr/bin/python3 scripts/freecad/run.py housing/entry.py verify
```

Generation overwrites the native FCStd and housing dist, using source parameters and canonical PCB inputs; no second visible board projects or old workspace fallback. Verify can also reopen the preserved native case using retained build metadata. Recompute/STEP/STL checks require the runtime and are not replaced by ZIP CRC. GUI review was blocked and remains not performed; do not infer visual qualification from retained previews.

All cable/fit/radio/USB/thermal/bench gates remain open. Qualified protected 1S 4.2V pack, 121mA/4.23V acceptance, supervised off-body charging, no TS cell-temperature monitoring. All SMT headers are JLC-fitted; no local-SMT or interchangeable THT variant.
